# 碧水沃野 · r16 规则推演：全情况穷举与遗漏检查

> 配套文档：`docs/规则书.md`（v0.2-draft-r16）
> 本文对 r16 植物规则做一次端到端的情况穷举：每个环节列出所有可能局面，标注当前规则**已覆盖**（给出章节出处）还是**遗漏/待拍板**（⚠️）。
>
> **r16.1 拍板记录（2026-09-05，已落回规则书正文）**：
> ① **多土地地块一次种满**（原 #15 ✅）——一次动作、1 枚种子，覆盖该格全部 `land_region`；每区域独立结算 / 计分（"多次计算"成立）/ 独立退种（§5.1 / §5.8 / §6.2）。
> ② **收获锁定区域**（原 #16 / #17 ✅）——区域内出现收获植物即整体锁定：任何玩家（含原主）不可再种、V_L 冻结、收获植物结构性免疫驱逐（§5.6.1）。
> ③ **区域退种**（原 #18 ✅）——以连通区域为单位：每次结算事件（闭合 / 驱逐）每位玩家退 1 枚，与株数无关；种子通胀问题消解（§5.4.1 / §5.6.2）。
>

## 六、战略/经济层面观察（非漏洞，拍板 #18 时一并考虑）

1. **种子通胀曲线**：若扩张株也全额退种（#18 当前字面），"种 1 传 N 退 N"会让种子越玩越多，种子稀缺性（开局各 2 枚）被瓦解。建议：扩张株不退种，或退种仅限"耗种子种下的源株"。
2. **先手双重优势**：种植顺序同时决定 ①闭合分水谁先收获（§5.5）②自动扩张多主占格（§5.4.2）。先手玩家在两条线上都占优，拍板时可考虑给后手补偿（如扩张占格改为"后来者占"或掷硬币）。
3. **种低级进高级区域 = 纯浪费动作**：规则合法但必然被驱逐；UI 必须在确认前明示后果（§2.4）。
4. **弃牌回合可种植**（#20 若拍板为"可以"）：弃牌变成"只种不放"的变体回合，比正常回合少承担放置风险，可能被玩家刻意利用——需确认是否接受。
5. **已闭合区域再种植 = 无风险的得分引擎**（#17 若水够）：区域内死亡格再种→立即结算→收获计分，每回合稳定产分且种子零损耗（种 1 退 1）。若认为过强，可限制"已闭合区域不可再种植"。

## 结论（r16.1 更新）

原 4 个硬缺口已在 r16.1 全部拍板并落回规则书正文：

1. **原 #15 多土地地块** → **一次种满**：一次动作、1 枚种子，覆盖该格全部 land_region；每区域独立结算 / 计分 / 退种，"多次计算"旧语由矛盾转为正式规则（§5.1 / §5.8 / §6.2）。
2. **原 #16 收获免疫驱逐** → **收获锁定区域**：禁种（含原主）+ 区域已闭合无法拼接引入新物种 → 收获植物结构上不可被驱逐（§5.6.1）。
3. **原 #17 再种植水量基数** → 含收获植物的区域整体禁种、V_L 冻结，问题消解；仅"全死亡"的闭合区域可再种，按结算时 V_L 现值（§5.6.1 / §5.6.2）。
4. **原 #18 种子通胀** → **区域退种**：每个连通区域每位玩家退 1 枚（与株数无关），扩张株不再产生额外退种（§5.4.1 / §5.6.2）。

仍开放的次级项（§9 现 #15–#18）：中心 EMPTY 不自动扩张的显式确认、弃牌回合可否种植、种植顺序写入时机矛盾、同级竞争计数基准（含破平链口径）。

### r16.1 带来的新平衡观察

- **重种同一区域变贵**：种 N 株退 1 枚 → 深耕一片地净耗 N−1 枚种子；广撒单株反而省种子（但每片只退 1 枚，纯靠自动扩张铺量的玩家闭合时收益也少）。
- **收获 = 终局锁分**：锁定区域的水量冻结 + 禁种，先闭合且水够的一方拿到不可被翻转的分数；"种高级物种进对手闭合区域强拆"的打法被彻底关闭。
- **全死亡区域可免费循环再种**（种 1 退 1、净耗 1 个动作）：水网后续增长可使再种植株收获——后手翻盘窗口保留，但仅限没有收获植物的闭合区域。
