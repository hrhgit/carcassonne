# 沃土播种植物与编辑期散布规范

> 适用范围：玩家在可种植沃土上播种后的植物视觉、编辑期布局与固定预制件烘焙。  
> 不适用范围：`MEADOW` 的环境草、石头、树桩或其他地表点缀。

## 1. 边界

“草、花、树”在这里是玩家可播种的三种植物轮廓，而不是自动铺在草地上的装饰。它们只在 `LAND` 对应的 `PlantingMask3D` 内出现：

- 裸土：不显示任何播种植物。
- 生长：显示由该土地拥有者播下的植物布局。
- 枯萎：在**相同位置、朝向、缩放**显示对应的枯萎模型；不能重新随机或换成环境装饰。
- `MEADOW`、`WATER`、河岸安全边距、地块外缘以及其他土地块都不是合法播撒区域。

这条边界让“有植物”持续表示玩家对沃土的种植状态，而不与地块的常驻环境细节混淆。

## 2. 植物原型

| 原型 | 主要轮廓 | 健康态 | 枯萎态 | 归属徽记 |
| --- | --- | --- | --- | --- |
| `soil_herb` 草本丛 | 多根茎、叶片、种穗组成的小簇 | 直立绿叶与金色种穗 | 倾倒的褐色干茎与种穗 | 根部六边徽记 |
| `soil_flower` 花卉 | 单主茎、叶片、五瓣花 | 奶白花瓣与中性色花心 | 倾斜茎与下垂褐色花头 | 茎部小环徽记 |
| `soil_sapling` 树苗 | 中性树干、分枝、低多边形树冠 | 三团绿树冠 | 裸干与分叉枯枝 | 树干束带徽记 |

三种模型都拥有一个名为 `OwnerMarker` 的单独材质槽。切换玩家时只替换这个小部件的颜色；树冠、花瓣、茎叶和干枯材质保持物种及状态的中性可读性，不能用整株染色替代。

## 3. 播撒算法

### 3.1 输入与输出

每次编辑期构建使用：

```text
PlantingMask3D（沃土多边形 + 排除区 + 安全边距）
+ PlantScatterProfile3D（每种模型的数量、足迹、间距、边距、簇参数）
+ 固定 seed
→ PlantScatterLayout3D（可审计的位置、朝向、缩放、显现阈值）
→ 固定 GrowingPlants / WitheredPlants 预制件层
```

运行时绝不运行随机采样，也不按边口拼装或重画植物。它只实例化已烘焙的地块／植物层，并选择裸土、生长或枯萎状态。

### 3.2 变量半径泊松式采样

布局使用固定种子的候选采样，而非均匀网格或完全独立随机：

1. 按 `placement_priority` 先放树苗，再放花卉，最后放草本丛。
2. 每个待放实例从种植掩码包围盒提出 36 个候选点；候选点必须落在掩码内部，且满足本种的边缘／水岸额外安全距离。
3. 每个候选点都和已接受点检查变量半径距离：

   ```text
   required_distance = r_a + r_b + max(gap_a, gap_b)
   ```

4. 在可行候选中，选取距离相邻植物和种植边界都更宽裕的点，避免树苗、花和草本互相穿模，也避免贴边。
5. 花卉可按 `cluster_chance` 在既有花附近的 `cluster_radius` 中提候选，因此读作自然的小簇；硬距离限制仍然生效。树苗和草本默认不借此形成密集同心团。

这一类蓝噪声／泊松盘采样会保留最低间距、避免规则棋盘感，并适合不规则的土壤多边形；Bridson 的经典方法正是为高效生成带最低间距的样本而提出。[Fast Poisson Disk Sampling in Arbitrary Dimensions](https://www.cs.ubc.ca/~rbridson/docs/bridson-siggraph07-poissondisk.pdf)

`PlantingMask3D` 的点内判断直接使用 Godot 的多边形判断，不从地表颜色或水面距离反推土地语义。[Godot Geometry2D 文档](https://docs.godotengine.org/en/stable/classes/class_geometry2d.html)

### 3.3 生长与枯萎

每条播撒记录附带稳定的 `reveal_threshold`。土地在生长早期只显示阈值以下的固定子集，随后逐步露出同一套位置；缺水时切到相同记录的枯萎实例。这既让覆盖范围随状态增长，又避免状态切换时植物“跳位”。

## 5. 构建与验收

重新调整掩码或任何物种配置后，先重烘焙，再运行 smoke：

```powershell
godot --headless --path . --script res://tools/build_soil_planting_bed.gd
godot --headless --path . res://scenes/visual_studies/soil_planting_study.tscn -- --study-smoke
```

Smoke 必须确认：

- 每个位置仍在 `PlantingMask3D` 中，且离边缘／水岸有足够距离；
- 所有两两足迹满足变量半径间距；
- 生长层和枯萎层拥有同一套固定位置；
- 三个物种都有独立的健康／枯萎轮廓与 `OwnerMarker`；
- 玩家颜色只替换 `OwnerMarker` 的材质。

正式地块的构建与验证命令为：

```powershell
godot --headless --path . --script res://tools/build_north_east_land_south_water_assets.gd
godot --headless --path . --script res://tools/build_north_east_land_south_water_plants.gd
godot --headless --path . res://scenes/visual_studies/north_east_land_south_water_3d_study.tscn -- --study-smoke
```
