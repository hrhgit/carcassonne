# 蔓延 / GrowCassonne — 玩法说明

## 概述
2-4人热座（同屏轮流）策略桌游。玩家在网格棋盘上放置地形卡、播种，
植物会在每回合自动蔓延到相邻同类地形。最终连片最大的玩家获胜。

---

## 基本规则

### 回合流程（每人每回合3步）
1. **放置地形卡** — 从公共牌堆抽一张随机地形，放到棋盘空格上
   - 相邻格必须已有地形（第一张除外）
2. **播种（可选）** — 在刚放的地形格上放一颗自己的种子
   - 每人初始5颗种子，每回合+1
3. **生长** — 你的植物自动蔓延到相邻的同类地形格（40%概率）

### 四种地形
| 地形 | 颜色 | 特点 |
|------|------|------|
| 草地 | 绿色 | 最常见 |
| 水域 | 蓝色 | 中等 |
| 森林 | 深绿 | 较少 |
| 荒漠 | 黄色 | 较少 |

### 蔓延规则
- 植物只会蔓延到**相邻（上下左右）且同类地形**的格子
- 蔓延是概率性的（40%），不是必然发生
- 不同玩家的植物**可以共存**在同一格上
- 每回合自动触发一次蔓延

---

## 多人模式

### 玩家设置
- 2-4人，每人一个颜色
- 玩家1 = 绿色 | 玩家2 = 蓝色 | 玩家3 = 橙色 | 玩家4 = 紫色

### 轮流机制
- 玩家轮流执行回合
- 每回合：抽地形 → 放地形 → 可选播种 → 触发生长
- 棋盘和种子池是**公共的**（所有玩家共用同一个棋盘）

### 种子分配
- 每位玩家独立计种子数
- 初始5颗，每回合结束+1
- 种子放的是**自己的颜色**

---

## 计分

### 游戏结束条件
- 总回合数用完（默认30回合，所有玩家共享）

### 得分计算
- **覆盖分**：你的植物覆盖的格数 × 1
- **连通分**：你的植物形成的连通区域数 × 5
- 连通 = 同色植物在相邻格上形成的连续区域

### 胜利条件
- 总分最高的玩家获胜
- 平局时，连通区域更少的玩家获胜（更集中）

---

## 策略提示

1. **地形控制** — 别只顾自己，也要阻止对手的连片
2. **种子时机** — 早期多种子建立据点，后期靠蔓延扩张
3. **地形搭配** — 连续放同类地形，为蔓延铺路
4. **阻挡** — 在对手可能蔓延的方向放不同地形
5. **集中 vs 分散** — 一个大大连片 > 多个小小区域

---

## 操作

| 操作 | 按键 |
|------|------|
| 放地形 | 左键点击空格 |
| 放种子 | 左键点击已放地形格 |
| 跳过播种 | 右键 |
| 重新开始 | R |

---

## 快速开始
1. 打开游戏，点击"开始游戏"
2. 玩家1放地形，可选播种，右键跳过
3. 自动轮到玩家2
4. 重复直到回合用完
5. 看谁的植物连片最大！
