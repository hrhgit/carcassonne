# 青菱沃野 · Qingling Meadow

> 一款基于方形地块拼接与边缘匹配的桌面策略游戏。玩家轮流拼放由**土地、水流、空地**构成的方形地块，在有限的水网里**种草、养花、植树**——让植物向相邻土地蔓延，只有持续获得足够水分的土地才能生长、收获与得分。

游戏名取自武汉市洪山区青菱湖：「青」对应水网，「菱」对应水生可种植作物，「围垦成田」呼应拼块玩法。旧视觉研究截图中的 `VERDANT WATERS` 仅作历史原型记录。

---

## 一句话玩法

两个人、55 张主地形牌与 8 块开局河流、一片正在扩张的草原。和卡卡颂一样拼牌、计分；不同的是你不是在抢城堡和道路，而是在**养植物**。每棵植物都要喝水，水从水网的**灌溉接口**接入——你要赶在对手之前，把自己的小园子养得满园春色。

## 核心机制

| 机制 | 说明 |
| --- | --- |
| **拼接** | 地块以 90° 旋转，同类型边口（土地/水流/空地）才能相接 |
| **种植** | 放置地块后，可在本回合刚放下、无植物的可种植土地上种下草/花/树 |
| **自动扩张** | 新地块与已种植地块相邻且土地连通时，植物自动长上去，不耗种子 |
| **驱逐** | 同一土地块内树 > 花 > 草，异种相遇高级驱逐低级（同级共存） |
| **供水** | 每个灌溉接口固定提供 2 点水；植物需水 = `need × 面积` |
| **全封闭结算** | 土地被围死时一次性分水：水够收获、不够死亡 |
| **计分** | 草 1 分 / 花 2 分 / 树 4 分；未封闭的花树减半 |

植物规则以 `docs/规则书.md`（r17 定稿）为权威依据，玩家视角见 `docs/玩家手册.md`。

## 技术栈

- **引擎**：Godot 4.6.1（`gl_compatibility` 渲染，GL Compatibility）
- **语言**：GDScript
- **美术**：低多边形 3D 地块预制件（`.tscn` / `.glb`），Blender 辅助建模
- **音效**：程序化生成（`tools/generate_sfx.py`），WAV 位于 `audio/sfx/`

### 工程结构

```
tablegame/
├─ project.godot          # 工程入口，主场景 start_menu.tscn
├─ scenes/                # 场景：开始菜单、主棋盘、地块/植物预制件、视觉研究
├─ scripts/               # 规则引擎与游戏逻辑
│   ├─ board_state.gd     # 棋盘状态：邻接、边口匹配、占格、土地/水网连通
│   ├─ rule_engine.gd     # 规则引擎
│   ├─ plant_engine.gd    # 植物引擎：种植、扩张、驱逐、封闭结算
│   ├─ tile_definition.gd # 地块静态定义（边口、预制件、朝向）
│   ├─ tile_catalog.gd    # 牌堆与规则定义→预制件映射
│   ├─ game_config.gd     # 玩家数量/颜色配置（Autoload）
│   └─ sfx_manager.gd     # 音效管理（Autoload）
├─ data/                  # 卡牌表 tiles.csv / tiles_classic.csv
├─ tools/                 # 构建/导入/冒烟脚本、音效生成、地块 3D 生成管线
├─ shaders/               # 水面、植被等着色器
├─ art/                   # 美术资产
├─ artifacts/             # 生成产物（预览图、构建结果等）
└─ docs/                  # 规则书、玩家手册、策划案与规范文档
```

## 运行

用 Godot 4.6.1 打开工程目录并运行即可；入口场景为 `scenes/start_menu.tscn`（主场景已在 `project.godot` 配置）。

```bash
# headless 冒烟测试（注意必须用 -- 分隔用户参数）
Godot_v4.6.1-stable_win64_console.exe --headless --path . -- --game-smoke
```

本地 Godot 可执行文件路径：`E:/Program Files/Godot_v4.6.1-stable_win64.exe/Godot_v4.6.1-stable_win64_console.exe`。

## 开发要点

- **静态定义与运行时状态分离**：`TileDefinition`（可复用 Resource）承载边口/拓扑/灌溉接点，`PlacedTile` 承载坐标、归属与生长状态。
- **水网不承载容量**：灌溉接口计数决定供水量（每接口 2 点），水网仅用于连通判定。
- **地块视觉使用固定预制件**：运行时只做实例化、定位、等比缩放与 90° 旋转，不按边口数据重绘。
- **植物散布可复现**：按「世界种子 + 地块定义种子 + 格子坐标」一次性散布，刷新结果一致。
