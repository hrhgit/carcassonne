# Kenney Nature Kit 2.1

This directory contains the complete set of 329 GLB models from the Kenney
Nature Kit 2.1 package. They are extracted verbatim from the tracked source
archive at `art/source/kenney/nature_kit/kenney_nature-kit.zip`.

The source archive contains all 3,626 original package entries and has SHA-256
`fa7974a0d342bfe63c38664ba9f8ec1a4aab8ea25f099bdc56870e33588c4d9d`.

The package is available under CC0 1.0. See `LICENSE.txt` for the license text
bundled with the original archive.

These models are a reusable art library. Game scenes must continue to use
fixed `.tscn` prefabs and deterministic `LAND`-mask plant placement; choosing a
model from this library must not redraw terrain, waterways, or tile ports at
runtime.
